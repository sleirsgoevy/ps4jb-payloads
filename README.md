# Archived repo

I'm fed up with maintaining an alternate universe of PS4/PS5 payloads. The scene settled on an entirely different SDK with a different payload format, and I'm only making things worse by sticking to this.

Everything of interest here will be either migrated to ps5-payload-sdk & moved out of the monorepo, or dropped in favor of whatever upstream project already handles the relevant task.

The ps4 branch has been dead for years, so I'm archiving it too. Not much to save there.
